# 정식 출시 전 체크리스트

## 1. 스토어 등록정보 (→ docs/store-listing.md)
- [ ] 한국어 앱 이름·간단한 설명·자세한 설명 교체 ("클래식" → "스테이지", 랭킹·오늘의 퍼즐 소개)
- [ ] 영어(en-US) 번역 추가
- [ ] 휴대폰 스크린샷 교체: `release/store_screenshots/ko/` 6장, 영어 번역에는 `en/` 6장
- [ ] 태블릿 스크린샷 추가(7인치·10인치): `tablet_ko/` 5장, 영어 번역에는 `tablet_en/` 5장
- [ ] 개인정보처리방침 웹 페이지를 `docs/privacy-policy.md` 최신본으로 (랭킹 데이터, 문의 이메일)
- [ ] 연락처 이메일 입력

## 2. Play 게임즈 서비스 게시
1. [ ] 최신 AAB를 비공개 테스트로 올리고 검토 통과
2. [ ] **Play 게임즈 서비스 → 테스터**에 등록된 계정의 휴대폰에서:
   - [ ] 앱을 열면 Play 게임즈 자동 로그인(화면 위에 환영 표시)
   - [ ] 러시 한 판 → 결과 화면에 "이번 주 n위"
   - [ ] 타이틀 왼쪽 위 트로피 → 랭킹 화면에 내 점수
3. [ ] 콘솔의 Play 게임즈 **설정** 진행 표시에서 "SDK를 APK에 추가하여 API 사용"이 완료로 바뀌었는지 (몇 시간 걸릴 수 있음)
4. [ ] **Play 게임즈 서비스 → 게시 → 검토 후 게시**
   - 게시 전에는 등록된 테스터만 랭킹 로그인 가능
   - 리더보드 이름(영어 기본값 "Rush High Score")과 한국어 번역 확인

## 3. 실제 휴대폰 점검
가능하면 최신 폰 1대 + 오래된·저사양 폰 1대.

**성능**
- [ ] 9x9 81~100탄: 헛수를 두었을 때 화면이 멈추지 않는지, 막힘 알림이 너무 늦지 않은지(1~2초 이내)
- [ ] 러시 30번째 퍼즐 이후에도 끊김 없이 부드러운지
- [ ] 오래 플레이해도(20분+) 느려지거나 음악이 끊기지 않는지

**소리**
- [ ] 메뉴·러시 3종·스테이지 3종 음악이 반복될 때 이음매에서 "툭" 끊기지 않는지
- [ ] 러시 남은 15초에 긴장 곡, 피버 때 피버 곡으로 바로 바뀌는지
- [ ] 홈 버튼·화면 끄기·전화 수신 때 음악이 멈추고, 돌아오면 이어지는지

**기능**
- [ ] 설정 → 의견 보내기 → 메일 앱이 열리고 받는 사람·제목·앱 버전이 채워지는지
- [ ] 오늘의 퍼즐: 풀고 나서 타이틀에 "오늘 완료!" 표시, 다음 날 연속 기록 +1
- [ ] 기기 언어를 English로 바꾸면 앱이 영어로 나오는지
- [ ] 태블릿: 가로·세로로 돌려도 게임이 이어지고, 휴대폰은 세로로 고정되는지
- [ ] 글자 크기를 크게(설정 → 디스플레이) 했을 때 게임 화면 글자가 넘치지 않는지

**기록**
- [ ] 앱을 지웠다 다시 설치했을 때 별 기록이 돌아오는지 (안드로이드 자동 백업, 같은 구글 계정)

## 4. 테스트 기간 동안
- [ ] 플레이 콘솔 **모니터링 및 개선 → Android vitals**에서 비정상 종료·ANR 확인
- [ ] 테스터 의견 메일 확인
- [ ] 대시보드의 비공개 테스트 요건(테스터 12명, 14일) 진행 상황
